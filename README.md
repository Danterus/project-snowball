# ❄️ Project Snowball - Скирмиш Варгейм в снежки

Тактическая пошаговая настольная игра в жанре скирмиш-варгейма, где дети играют в снежки во дворе.

## 🌟 Особенности игры:
- **Гексагональная карта из 7 зон**: центральный холм дает тактическое преимущество (+1 к прицелу), а зоны плавно перетекают друг в друга.
- **Разнообразные персонажи**: каждый герой имеет свои параметры здоровья, дальности прицела, урона и скорости шага.
- **Карточки снежков**:
  - ⚪ *Обычный*: стандартная дальность и урон.
  - 🪨 *Тяжелый*: сокрушительный урон (+2 HP), но штраф кубика (-1).
  - ⚡ *Легкий*: летит точно и быстро, бонус к броску кубика (+2).
  - 🧊 *Ледяной осколок*: замораживает соперника (-2 шага на следующий ход).
  - 💨 *Рассыпчатый*: снег в глаза (-1 к дальности прицела цели).
- **Справедливая механика броска D6**:
  - Дистанция $\le$ 1/2 прицела: попадание при **2+**
  - Дистанция от 1/2 до максимального прицела: попадание при **4+**
  - Свыше максимального прицела: за каждую клетку **+1 к сложности броска**
- **Режимы игры**:
  - 🤖 Одиночная игра против умных ботов
  - 🛋️ Локальный Hotseat на одном экране
  - 🌐 **Сетевой мультиплеер P2P (WebRTC через PeerJS)** — работает между разными компьютерами и телефонами без выделенного сервера!

## 🚀 Как запустить:
Просто откройте файл `index.html` в любом браузере или запустите через GitHub Pages.
